# CLAUDE.md

This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

## Overview

This is a personal Neovim configuration using **Packer.nvim** for plugin management. The configuration is written in Lua and follows a modular structure with core settings in `lua/dlovric/` and plugin-specific configurations in `after/plugin/`.

## Common Commands

### Plugin Management
```bash
# Update/install plugins after modifying lua/dlovric/packer.lua
nvim
:PackerSync

# Compile plugin changes
:PackerCompile
```

### Reloading Configuration
- In normal mode: `<leader><leader>` (Space twice)
- Or: `:so` to source the current file

### Starting Neovim
```bash
# Open in current directory (auto-opens nvim-tree)
nvim .

# Open specific file
nvim path/to/file.lua
```

## Architecture

### Initialization Flow
```
init.lua (entry point)
  ↓
require("dlovric")
  ↓
lua/dlovric/init.lua
  ├─→ remap.lua    (custom key mappings)
  └─→ set.lua      (editor options)

Packer loads plugins
  ↓
after/plugin/*.lua (plugin configurations loaded after plugins)
```

### Directory Structure
- **`init.lua`**: Bootstrap file, sets clipboard and loads main config module
- **`lua/dlovric/`**: Core configuration modules
  - `packer.lua`: Plugin declarations and installation
  - `remap.lua`: Custom keybindings (leader key is Space)
  - `set.lua`: Editor settings (tabs, line numbers, undo, etc.)
- **`after/plugin/`**: Plugin-specific configurations (loaded after plugins initialize)
  - Each file configures one plugin/feature (lsp.lua, treesitter.lua, etc.)
- **`plugin/packer_compiled.lua`**: Auto-generated by Packer (do not edit manually)

### LSP Setup

LSP configuration is in `after/plugin/lsp.lua` using **lsp-zero** (v1.x):

**Installed Language Servers**:
- `pyright` (Python)
- `html`, `cssls` (Web)
- `jdtls` (Java)

**Adding a new language server**:
1. Open `after/plugin/lsp.lua`
2. Add server name to the `lsp.ensure_installed()` table
3. Restart Neovim or run `:LspInstall <server-name>`

**LSP Keymaps** (available in LSP-attached buffers):
- `gd` - Go to definition
- `K` - Hover documentation
- `<leader>vca` - Code actions
- `<leader>vrn` - Rename symbol
- `<leader>vrr` - Show references
- `[d` / `]d` - Navigate diagnostics
- `<leader>f` - Format buffer

### Treesitter

Syntax highlighting configuration in `after/plugin/treesitter.lua`.

**Installed parsers**: python, java, javascript, html, css, lua, vim, vimdoc

**Adding a new parser**:
Treesitter auto-installs missing parsers when opening files, or manually:
```vim
:TSInstall <language>
```

### Debugging (DAP)

Python debugging is configured in `after/plugin/dap.lua`:

**Debug keymaps**:
- `<leader>db` - Toggle breakpoint
- `<leader>dc` - Continue/start debugging
- `<leader>dn` - Step over
- `<leader>ds` - Step into
- `<leader>do` - Step out
- `<leader>dr` - Open REPL
- `<leader>dt` - Test method (Python)

**Debugger path**: `~/.local/share/nvim/mason/packages/debugpy/venv/bin/python`

### Claude Code Integration

Claude Code AI assistant integration in `after/plugin/claudecode.lua`:

**Prerequisites**:
- Claude Code CLI must be installed and authenticated
- Run `claude doctor` to verify installation
- Ensure `claude` command is in your PATH

**Claude Code keymaps**:
- `<leader>cc` - Toggle Claude terminal
- `<leader>cf` - Focus Claude terminal
- `<leader>cs` - Send visual selection to Claude (visual mode)
- `<leader>cm` - Select Claude model
- `<leader>cb` - Add current buffer to Claude context
- `<leader>ca` - Accept diff proposed by Claude
- `<leader>cd` - Deny/reject diff proposed by Claude

**Configuration**: Terminal opens on the right side at 30% width. Auto-starts server when Neovim launches.

### Key Navigation Tools

**Telescope** (fuzzy finder) - `after/plugin/telescope.lua`:
- `<leader>ff` - Find files
- `<leader>fw` - Live grep (search in files)
- `<leader>fg` - Git files
- `<leader>fz` - Fuzzy find in current buffer

**Harpoon** (file marks) - `after/plugin/harpoon.lua`:
- `<leader>a` - Add current file to marks
- `<leader>h` - Toggle Harpoon menu
- `<leader>1-6` - Jump to marked file 1-6

**nvim-tree** (file explorer) - `after/plugin/nvim-tree.lua`:
- `<leader>e` - Toggle file tree
- Auto-opens when starting with `nvim .`

### Adding a New Plugin

1. Edit `lua/dlovric/packer.lua`
2. Add plugin declaration in the `packer.startup()` function:
   ```lua
   use 'author/plugin-name'
   ```
3. Run `:PackerSync` in Neovim
4. Create configuration file in `after/plugin/plugin-name.lua` if needed

### Important Settings (lua/dlovric/set.lua)

- **Indentation**: 4 spaces, tabs converted to spaces
- **Line numbers**: Enabled with relative numbering
- **Undo history**: Persistent in `~/.vim/undodir/`
- **Swap/backup**: Disabled
- **Color column**: 120 characters
- **Clipboard**: Synced with system (`unnamedplus`)

### Git Integration

**Fugitive** (`after/plugin/fugitive.lua`):
- `<leader>gs` - Git status

Standard git commands work in terminal mode or via `:!git` commands.

## Notes

- Leader key is **Space**
- Configuration uses Lua (not Vimscript)
- Plugin configurations are isolated in `after/plugin/` for maintainability
- When modifying keymaps, edit `lua/dlovric/remap.lua` for global maps or the specific plugin file in `after/plugin/` for plugin-specific maps
